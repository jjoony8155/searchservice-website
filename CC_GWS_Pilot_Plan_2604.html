개요 및 도입 배경
CC사업부 전체 일괄 도입보다, 서비스기획본부·마케팅본부 중심으로 우선 3개월 시범운영을 진행하여 실질적인 업무 효과를 검증하고, 전사 확산의 표준 모델을 수립합니다.

🤖 내부 실무자 AI 활용 — 자동화 및 관리툴 사례
마케팅전략팀
주간 트렌드 키워드 자동 리포트
네이버 쇼핑 트렌드 키워드를 매주 자동으로 수집·분석하여 메일로 발송하는 자동화 시스템. itemscout API와 AI를 결합해 수동 수집 작업을 완전 자동화했으며, GWS 도입 후 사내 Gmail 전체 발송으로 확장 예정.
🔧 기술 스택 및 구현
itemscout API(네이버 쇼핑) 연동 → AI 데이터 정제 → 자동 메일 발송. 현재 보안 이슈로 팀장급 수신 중이며, GWS 도입 후 사내 Gmail로 전체 발송 전환 예정.
📅 운영 방식
매주 월요일 오전 자동 발송. 수신 희망자는 별도 신청으로 추가 가능. 데이터는 AI 정제 기반으로 일부 오차 가능성이 있어 참고 활용 권장.
✅ 수동 수집 → 자동화 ✅ AI 데이터 정제 ✅ GWS 도입 후 전사 배포 예정
📄 리포트 샘플 보기
마케팅전략팀
다나와 SA광고 모니터링 대시보드
수천 개 광고 키워드를 수동으로 Excel 비교하던 작업을 AI 웹 대시보드로 전환. 대화형 코딩으로 개발해 별도 개발 인력 없이 구현했으며, 6가지 이슈 유형을 자동 감지해 조기 대응이 가능합니다.
🔧 구현 방식
AI 도구와의 대화로 코드 작성 없이 웹 대시보드 구현. 엑셀 업로드 → 자동 비교 분석 → 이슈 자동 감지 → 리포트 자동 생성. 비개발자도 기능 추가·수정 가능.
⚡ 주요 기능 — 6가지 자동 감지
🚨 클릭 0 감지 — 전일 클릭 있었는데 금일 0인 키워드
⚠️ 클릭 N%↓ 감지 — 설정 기준 이상 클릭 감소 키워드
🔍 고호출 클릭0 — 호출수 충분하지만 클릭 없는 키워드
📭 광고 공급부족 — 빈슬롯 6으로 광고 상품 전혀 없는 상태
📉 호출수 급감 — 전일 대비 호출수 50% 이상 감소
📋 전체 분석 대상 — 필터·중복 제거 후 전체 현황
✅ 수동 비교 → 자동 감지 ✅ 비개발자 활용 가능 ✅ 조기 이상 감지
🖥 대시보드 스크린샷 보기
마케팅본부 마케팅전략팀
주간 트래픽 리포트 대시보드 + AI 분석
기존 구글시트 수작업으로 주간 트래픽 현황을 정리해 메일 발송하던 방식을 대시보드 자동화 + AI 분석 리포트로 전환. DAU 지표와 채널별 현황을 자동 시각화하고 AI가 시장 동향 분석 코멘트를 자동 생성합니다.
🔧 구현 방식
DAU(Organic/Paid), 디바이스별(PC웹·M웹·APP), 채널별(Direct·네이버·구글 등) 지표 자동 시각화. AI가 D램·GPU 시황, 계절적 요인 등 시장 맥락을 반영한 분석 코멘트 자동 생성.
⚡ 주요 기능
WoW·YoY 자동 비교, 수치 이상 자동 감지 및 하이라이트. AI 시장 분석 코멘트 자동 생성. 매주 자동 발송으로 담당자 리포트 작성 시간 대폭 단축.
✅ 구글시트 수작업 → 자동화 ✅ AI 분석 코멘트 자동 생성 ✅ 리포트 작성 시간 단축
🔗 대시보드 바로가기
검색서비스팀 · Cowave
형태소 오분석 자동 감지 시스템
다나와·에누리 검색 서비스의 형태소 분석 결과를 월 16만 건 이상 수작업으로 검토하던 구조를 AI 자동화로 전환. 브라우저 기반 도구로 엑셀 업로드 후 AI가 오분석 여부를 자동 판단합니다.
🔧 구현 방식
브라우저 단독 실행(GitHub Pages 배포). 엑셀 업로드 → AI가 오분석 여부 자동 판단 → 결과 다운로드. AI 도구와의 대화로 개발하여 코드 작성 최소화.

오분석 기준: 형태소 분석기가 단어를 의미 없는 음절 조각으로 잘못 분리한 경우.
예) 텔루릭스 → [텔·루릭·스] 오분석 ✅
예) 삼성전자 → [삼성·전자] 정상 ✅
