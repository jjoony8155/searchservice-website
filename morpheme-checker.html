오분석
형태소 분석기가 하나의 단어를 의미없는 조각으로 잘못 쪼갠 경우
잘못된 단어: 푸,드렐라 → 올바른 단어: 푸드렐라
잘못된 단어: 텔,루릭,스 → 올바른 단어: 텔루릭스
잘못된 단어: 차,콜체스터 → 올바른 단어: 차콜,체스터
입력법
· 잘못된 단어: 형태소가 잘못 분리된 조각들을 콤마(,)로 구분
· 올바른 단어: 실제로 인식되어야 할 단어, 2개 이상이면 콤마(,)로 구분
· 카테고리: 해당 상품이 속한 카테고리 선택 (AI 학습 품질 향상)
💡 언제 등록하나요? · 검수 결과에서 AI가 맞게 잡은 오분석인데 케이스에 없는 경우, 또는 직접 발견한 오분석 패턴을 등록하세요. 등록하면 다음 분석부터 즉시 반영됩니다.
✅ 정상 케이스 추가 AI 오감지 교정
정상
AI가 오분석으로 잘못 감지했지만 실제로는 정상 분리인 경우
예시: 줄,사각,접시 → 줄 / 사각 / 접시 는 각각 의미있는 단어 → 정상
예시: LG,전자 → LG / 전자 는 정상 분리
입력법
· 정상 단어: AI가 오분석으로 잡은 형태소 조각들을 콤마(,)로 입력
· 메모: 왜 정상인지 간략히 메모 (선택사항)
💡 언제 등록하나요? · 검수 결과에서 AI가 오분석으로 잡았는데 실제로는 정상인 경우 등록하세요. 등록하면 AI가 동일 패턴을 다음 분석부터 오분석으로 잡지 않습니다.

⚙️ 1단계 · 규칙 기반 필터 (AI 호출 전 스킵)

분석 시작 전 아래 어절 유형은 AI 호출 없이 정상(N)으로 자동 처리됩니다. 형태소 분석기는 각 어절마다 원문파트 + 분리파트들을 출력하므로, 영숫혼합 어절의 모든 파트를 일괄 스킵합니다.

어절 유형 예시 어절 형태소 출력 예시 처리

숫자만 100 / 2000 / 32 100 스킵
영숫·특수 혼합
(모델번호)		 15AHP10 / KMM26237PP
KMM26237B2 / P261MPT106		 15AHP10, 15, AHP, 10
→ 원문+분리파트 전부 스킵		 전부 스킵
숫자+한글 10코어 / 5부 / 30개입 10, 코어 스킵
영문+한글 A라인 / H형 / DD로고 A, 라인 스킵
한글+숫자 주택2 / 세이브존04 주택, 2 스킵

✅ 제조사명 중복 파트 스킵: 형태소 앞부분에 제조사명이 중복으로 붙는 경우 자동 제거   예) 브롬톤, 브롬톤, 카펜더, 팬츠 → 두 번째 브롬톤 스킵
💡 현재 스킵률 약 4~5% (의류 데이터 기준). 분석 시작 시 토스트로 실시간 확인 가능.
🤖 2단계 · AI 오분석 판단 기준

규칙 필터를 통과한 한글 어절은 AI가 아래 기준으로 오분석 여부를 판단합니다.

📌 기본 원칙 — 의미없는 음절 조각으로 잘못 분리된 경우가 오분석
형태소 분리 결과 판정 이유
푸드렐라 → [푸, 드렐라] 오분석 의미없는 조각
텔루릭스 → [텔, 루릭, 스] 오분석 모두 의미없는 조각
삼성전자 → [삼성, 전자] 정상 각각 의미 있음
깨끗한나라 → [깨끗, 한, 나라] 정상 각각 의미 있음
📌 외래어 합성어 — 분리된 각 파트가 독립 의미를 가지면 정상
예시 판정 이유
힐링쉴드 → [힐링, 쉴드] 정상 healing + shield 각각 의미O
캐디백 → [캐디, 백] 정상 caddie + bag 각각 의미O
터치안티포그 → [터치, 안티, 포그] 정상 touch + anti + fog 모두 의미O
반바지 → [반, 바지] 합성어 반(한글2자) + 바지(한글2자) 각각 의미O
세미크롭 → [세미, 크롭] 합성어 semi + crop 외래어 각각 의미O
뉴발란스 → [뉴, 발란스] 오분석 브랜드 고유명사, 발란스 단독 의미X
이클립테인 → [이클립, 테인] 오분석 조어, 각 조각 의미X
📌 모델명·단위명 분리 — 다나와 색인 규칙에 의한 정상 처리 (오분석 아님)
모델명 기본 분리: TFX255GS → TFX, 255, GS · P261MPT106 → P, 261, MPT, 106
추가 색인 텀 ① 1byte 조합: KMM26237B2 → ..., B2(추가) · oled77c2fna → ..., c2(추가)
추가 색인 텀 ② 3byte 조합: a1b2 → ..., a1b, 1b2(추가)
추가 색인 텀 ③ 특문 제거: MVVJ2KH/A → ..., KHA(추가) · Y540-15IRH → ..., 54015(추가)
풀텀 추가 색인: abc123 → abc, 123, abc123(추가)
단위명 분리: 10cm → 10, cm, 10cm · 500GB → 500, GB, 500GB
패턴 경계 분리: lg전자 → lg, 전자 · 2025그램 → 2025, 그램
