오분석
형태소 분석기가 하나의 단어를 의미없는 조각으로 잘못 쪼갠 경우
잘못된 단어: 푸,드렐라 → 올바른 단어: 푸드렐라
잘못된 단어: 텔,루릭,스 → 올바른 단어: 텔루릭스
잘못된 단어: 차,콜체스터 → 올바른 단어: 차콜,체스터
입력법
· 잘못된 단어: 형태소가 잘못 분리된 조각들을 콤마(,)로 구분
· 올바른 단어: 실제로 인식되어야 할 단어, 2개 이상이면 콤마(,)로 구분
· 카테고리: 해당 상품이 속한 카테고리 선택 (AI 학습 품질 향상)
💡 언제 등록하나요? · 검수 결과에서 AI가 맞게 잡은 오분석인데 케이스에 없는 경우, 또는 직접 발견한 오분석 패턴을 등록하세요. 등록하면 다음 분석부터 즉시 반영됩니다.
✅ 정상 케이스 추가 AI 오감지 교정
정상
AI가 오분석으로 잘못 감지했지만 실제로는 정상 분리인 경우
예시: 줄,사각,접시 → 줄 / 사각 / 접시 는 각각 의미있는 단어 → 정상
예시: LG,전자 → LG / 전자 는 정상 분리
입력법
· 정상 단어: AI가 오분석으로 잡은 형태소 조각들을 콤마(,)로 입력
· 메모: 왜 정상인지 간략히 메모 (선택사항)
💡 언제 등록하나요? · 검수 결과에서 AI가 오분석으로 잡았는데 실제로는 정상인 경우 등록하세요. 등록하면 AI가 동일 패턴을 다음 분석부터 오분석으로 잡지 않습니다.

⚙️ 규칙 기반 필터 안내

분석 시작 전 아래 규칙에 해당하는 형태소는 AI 호출 없이 정상(N)으로 자동 처리됩니다. API 비용 절감 효과가 있습니다.

규칙 예시 처리 설명
형태소 1개 NIKE  /  32GB 정상 스킵 분리 자체가 없으므로 오분석 여부 판단 불필요
숫자끼리 3,2  /  2,5,6 정상 스킵 숫자는 숫자끼리 붙는 것이 정상
숫자 + 영문 조합 32,GB  /  s,25  /  4,TB 정상 스킵 숫자+영문 분리는 정상 패턴
의미있는 영단어 분리 nike,air  /  black,set  /  sport,max 정상 스킵 각 파트가 3글자 이상 영단어면 의미있는 분리로 판단
브랜드명 영문 분리 L,G  /  푸,드렐라  /  차,콜체스터 AI 분석 2글자 이하 영문 분리 또는 한글 포함 시 AI 판단
약어 글자 분리 U,S,B  /  L,E,D AI 분석 하나의 단어를 글자로 쪼개는 것은 오분석
💡 참고: 분석 시작 시 규칙 필터로 걸러진 건수가 토스트 알림으로 표시됩니다. 필터 효과가 낮으면 규칙을 추가·조정하여 비용을 더 절감할 수 있습니다.
